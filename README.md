
# a-shaman-k.github.io

Personal website built with Jekyll and published through GitHub Pages.

## Updating the site

- Edit `about.md` to change the biography and links.
- Put your headshot at `assets/images/profile.jpg`; the site will use it automatically.
- Put your CV PDF at `assets/Aashman-CV.pdf`.
- Add a blog post in `_posts` as `YYYY-MM-DD-title.md`.
- Add an expository mathematics article in `_articles` as `title.md`.

Posts and articles need front matter such as:

```yaml
---
title: "A useful title"
date: 2026-07-18
excerpt: "A short one-sentence introduction."
---
```

Maths is supported using MathJax: inline `$x^2$`, or displayed `$$x^2$$`.
